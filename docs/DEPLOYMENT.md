# 本地启动与部署准备

本仓库不包含生产密钥、真实学生资料或已发布配置。请先在测试环境完成启动和授权验收。

## 环境配置

复制`.env.example`到`.env.local`。浏览器与服务端Supabase配置需要指向同一个受支持实例，并按平台要求传递租户标识。`NEXT_PUBLIC_`值会进入客户端包，只有允许浏览器持有的公开配置可以放入其中。不要把服务角色密钥、超星应用secret或私密模型凭据写入公开变量。

认证回跳由平台认证代理完成，`src/lib/auth.ts`是当前实现依据。跨域与回调地址需要在服务提供方配置；切换域名后不能假定原回调继续有效。平台SDK还可能依赖运行环境注入的凭据，因此普通Next.js托管不能自动替代超星平台服务。

## 数据库

- 模型位于`src/db/schema.ts`，迁移位于`drizzle/`。
- 名册种子与学号回填已移除，不会自动导入真实班级。
- `0015_export_role_boundary.sql`约束已认证用户的角色自助修改。须先由管理员审阅，再在测试库按迁移顺序执行。
- 教师身份由可信管理员赋予，不能通过学生表单切换。
- Supabase RLS与应用授权均需验证；不要为方便演示关闭RLS。
- 现有`drizzle.config.ts`为生成迁移的占位连接；没有配置真实迁移连接，不能直接据此推送生产库。

## 检查命令

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm typecheck
pnpm lint
pnpm test:unit
pnpm build
pnpm start
```

默认开发和生产命令使用Next.js CLI。平台脚本另行保留，运行前请检查其中的端口管理和容器配置，不在共享机器上直接运行会清理端口的旧开发脚本。

## 发布前验收

使用独立的学生与教师测试账号，检查首次核验、拒绝越权、十二卡片保存、媒体权限、ZIP导入、文档解析、流式评价、版本重交及教师材料下载。评分变更必须能说明来源。请验证对象存储容量、文件清理、并发、大文件内存及ZIP解压限制。本次整理没有执行数据库迁移或发布网站。
