# 导出整理版差异

源项目通过超星诺亚“导出项目”获得。本地保留原始导出用于核对，仓库只包含净化后的工作副本。

## 保留

现有页面、业务组件、29个HTTP路由、数据库模型、原有迁移序列、十二张回顾文案、三阶段记录、分享圈、ZIP作品处理、教师评价与下载流程。

## 主流项目组织

继续采用Next.js全栈分层结构；补充README、架构图、接口说明、部署边界、环境变量模板、Git忽略规则、pnpm命令、Node.js规则测试及GitHub Actions。

## 净化和修正

1. 移除平台内部状态文件，忽略运行产物、环境文件、上传目录及日志。
2. 保留名册表结构，删除真实名单种子、整表重置和学号回填。新实例名册需管理员配置。
3. 将表单内具体学号示例替换为虚构数字。
4. `score-floor.ts`保留兼容接口，但不再按姓名限定成绩或凭空填分；`class-benchmark.ts`不再提供隐藏分数锚点。
5. 资料补全接口不接受学生请求提升为教师；附加角色变更数据库触发器，防止绕开接口直接写角色。迁移仅作为文件提供，未对原站数据库执行。
6. 默认脚本改为标准Next.js启动构建；旧平台脚本保留为`:coder`命令。npm配置恢复完整性验证默认行为。

## 已知边界

- 原项目功能记录和代码并不等于每个真实账号链路均已测试。教师端本轮仅源代码核对。
- 超星SDK、Supabase、对象存储、AI与文档解析仍需配置，不能声称完全独立部署。
- 数据库访问策略、文件归属、ZIP解压资源限制和角色迁移需要独立验收。
- 原站评分界面存在既有数据；本仓库没有导入、重算或修改这些成绩。
- 没有对连接中的平台项目发送AI指令、部署、清空数据或提交学生作品。

7. 文件存储客户端改为请求时延迟创建，避免源码构建阶段要求真实平台密钥；补充服务器密钥占位和 Webpack 兼容构建命令。
